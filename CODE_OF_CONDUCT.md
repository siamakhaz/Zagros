# Code of Conduct

Zagros follows the Contributor Covenant Code of Conduct, version 2.1.

We are committed to a welcoming, professional, harassment-free community. Contributors must communicate respectfully, accept constructive feedback, and avoid harassment, discrimination, intimidation, or disclosure of private information.

Project maintainers may remove, edit, or reject contributions or participation that violate these expectations.

For conduct concerns, use the private contact method listed in `SECURITY.md` or the repository owner's private GitHub contact channel.

This policy is based on the Contributor Covenant 2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
